🥛 Blog Bovinocultura de Leite
👨‍💻 Kauã Bevilacqua
O Blog Bovinocultura de Leite é um projeto de desenvolvimento web criado para apresentar informações sobre a criação de gado leiteiro, produção de leite, alimentação, manejo, saúde e bem-estar dos animais.

O projeto foi desenvolvido com o objetivo de colocar em prática conhecimentos de HTML5, CSS3 e JavaScript, criando uma página moderna, organizada, responsiva e interativa.

📌 Sobre o Projeto
A bovinocultura de leite é uma atividade importante para o agronegócio e para a produção de alimentos.

Pensando nisso, este projeto apresenta conteúdos relacionados à atividade leiteira por meio de uma interface simples e intuitiva, permitindo que o usuário conheça um pouco mais sobre:

🐄 Bovinocultura de leite;
🥛 Produção de leite;
🌾 Alimentação dos animais;
💧 Importância da água;
🩺 Saúde do rebanho;
🏡 Bem-estar animal;
🧑‍🌾 Manejo na propriedade;
📷 Imagens relacionadas à atividade.

🎨 Interface
O projeto utiliza uma interface baseada em cards, permitindo organizar os conteúdos em diferentes seções.

As cores foram escolhidas para representar elementos relacionados ao campo, à produção rural e à tecnologia.

O layout também foi desenvolvido para funcionar em diferentes tamanhos de tela.

📱 Responsividade
O blog foi desenvolvido pensando em diferentes dispositivos:

💻 Computadores;
💻 Notebooks;
📱 Smartphones;
📲 Tablets.
O conteúdo se adapta ao tamanho da tela para proporcionar uma melhor experiência ao usuário.

🌙 Dark Mode
Uma das funcionalidades do projeto é o Dark Mode.

O usuário pode alternar entre o modo claro e o modo escuro através de um botão desenvolvido com JavaScript.

Essa funcionalidade também permite praticar conceitos de:

Manipulação do DOM;
Eventos de clique;
Classes CSS;
Alteração dinâmica da interface.
